# ComfyUI (컴피유아이)

> [!summary]
> ComfyUI는 [[Stable Diffusion]]·Flux 등 오픈소스 이미지 모델을 위한 **노드 기반** 사용자 인터페이스다. 각 처리 단계(모델 로드·프롬프트·샘플러·[[LoRA (경량 파인튜닝)]]·업스케일)를 시각적 노드로 연결해 복잡한 생성·편집 파이프라인을 만들 수 있다.

## 핵심 개념
- **노드 기반 UI**: 각 처리 단계가 박스(노드)이고, 선으로 연결해 데이터 흐름을 만든다. After Effects·Blender의 노드 그래프와 비슷한 느낌.
- **장점 — 투명성**: "무엇이 어떻게 처리되는지" 눈에 보인다. 숨은 파라미터 없음.
- **장점 — 재현성**: 워크플로우 전체를 JSON/PNG 메타데이터로 저장·공유 가능. 같은 결과를 똑같이 재현.
- **장점 — 성능**: Automatic1111보다 메모리 효율적. 저사양 GPU에서도 큰 모델을 돌릴 수 있는 경우가 많다.
- **단점**: 초심자 진입 장벽이 높다. "그냥 이미지 한 장 뽑고 싶다"면 Automatic1111·Fooocus가 낫다.
- 주 사용자: 프로 아티스트, VFX 스튜디오, 자동화 파이프라인을 짜는 개발자.

## 상세 설명
ComfyUI가 특별한 이유는 **복잡한 편집·합성 파이프라인을 재현 가능한 워크플로우로 고정**할 수 있다는 점이다. 예: "원본 사진 → 얼굴만 세그먼트 → LoRA 적용해 표정만 바꾸기 → 배경만 따로 업스케일 → 합성 → 색 보정" 같은 7단계 작업을 노드 그래프로 만들면, 이후 수백 장의 사진에 같은 파이프라인을 일관되게 적용할 수 있다. 이 때문에 **배치 처리·A/B 테스트·자동화**가 필수인 영역에서 사실상 표준이다.

## 예시
- 쇼핑몰 제품 사진 500장에 "흰 배경 제거 → 그림자 합성 → 통일된 스튜디오 배경 삽입" 워크플로우 일괄 적용
- 영상 제작 파이프라인에서 매 프레임을 ComfyUI 워크플로우에 통과시켜 스타일 트랜스퍼
