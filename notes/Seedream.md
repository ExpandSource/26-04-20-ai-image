# Seedream (씨드림)

> [!summary]
> Seedream은 ByteDance(TikTok 모회사)가 개발한 이미지 생성 모델 시리즈다. 고해상도 직출력·한자/한글 등 CJK 텍스트 렌더링·빠른 속도로 강점을 가지며, 2025~2026년 미국·중국 양쪽 이미지 AI 경쟁의 핵심 플레이어로 떠올랐다.

## 핵심 개념
- **개발사**: ByteDance. Jimeng(중국 내수) / Seedream(글로벌)으로 라인업이 나뉜다.
- **강점 1 — 고해상도**: 2K·4K 이미지를 업스케일 없이 한 번에 생성. 인쇄물·포스터 작업에 유리.
- **강점 2 — 텍스트 렌더링**: 이미지 속 한자·한글·영어 글자를 정확히 써낸다. 포스터·광고·간판 디자인에 강점.
- **강점 3 — 속도**: 같은 품질 기준에서 [[Midjourney]]·[[Nano Banana]] 대비 상당히 빠른 편.
- **접근 경로**: ByteDance 자체 플랫폼(Doubao, Jimeng), 일부 서드파티 AI 허브(Fal, Replicate 등).
- **주의**: 데이터 주권·모델 가중치 투명성에 대한 논란이 있다. 개인정보·민감 이미지는 업로드 시 주의.

## 상세 설명
Seedream은 중국 AI 산업이 이미지 생성 분야에서도 글로벌 수준에 도달했음을 보여준 대표 모델이다. 특히 **아시아 언어 텍스트 렌더링**과 **포스터·광고 품질의 고해상도 출력**은 기존 서구권 모델이 오래 약했던 영역이어서, 한국·일본·중국 사용자에게는 실질적 가치가 크다. 다만 서비스 접근성이 영어권 대비 떨어지고, 엔터프라이즈 도입 시에는 데이터 정책을 반드시 검토해야 한다.

## 예시
- "설 명절 전단지 포스터, 중앙에 '福' 한자, 상단에 회사명 한글, 하단에 행사일 숫자" → Seedream이 세 종류 문자를 정확히 배치
- 4K 풍경 사진 생성 → 프린트·배너 소재로 바로 사용
