# Inpainting (인페인팅) / Outpainting (아웃페인팅)

> [!summary]
> 인페인팅은 이미지의 **일부 영역만 AI가 새로 그려 넣는** 편집 기법이고, 아웃페인팅은 이미지의 **바깥쪽을 자연스럽게 확장**하는 기법이다. 사진에서 원치 않는 물체를 지우거나, 좁은 구도를 넓히거나, 특정 부분의 색·소재만 바꾸는 데 쓰인다.

## 핵심 개념
- **인페인팅**: 마스크로 가린 영역만 AI가 새로 채운다. 원본의 다른 부분은 그대로 유지된다. ("사진 속 지나가는 사람 지워줘" / "이 벽지를 꽃무늬로 바꿔줘")
- **아웃페인팅**: 기존 이미지의 가장자리 바깥쪽을 AI가 상상해 그려낸다. 인스타 정사각형 사진을 16:9 와이드로 확장 같은 용도.
- **기반 기술**: 주로 [[Diffusion Model (확산 모델)]]의 노이즈 복원 과정에서 마스크 영역만 새로 생성하는 방식으로 동작한다. [[AutoRegressive Model (자기회귀 모델)]] 기반 서비스도 이제 대화형으로 같은 작업을 수행한다.
- 프롬프트는 "**무엇으로 바꿀지**"를 명시해야 한다. 그냥 "지워줘"보다 "벽돌 벽으로 자연스럽게 이어지게 해줘"가 훨씬 잘 통한다.

## 상세 설명
대부분의 실사용자에게 이미지 AI의 진짜 가치는 "처음부터 그리기"보다 **이미 가진 사진을 고치기**에 있다. ChatGPT·Gemini 같은 채팅형 도구에서는 "여기서 XX만 지워줘" 같은 자연어 지시만으로 작동한다. [[Stable Diffusion]]·[[ComfyUI]] 환경에서는 마스크를 직접 그리고 denoising strength 같은 파라미터를 조절하는 수동 방식이 가능하다.

## 예시
- 관광지 사진에서 인파 지우기 → "사람들을 제거하고 배경의 건물과 자연스럽게 이어지게"
- 1:1 가족사진을 16:9 TV 배경으로 → 아웃페인팅으로 좌우 확장
- 제품 사진의 배경색만 바꾸기 → 제품을 제외한 영역을 인페인팅
